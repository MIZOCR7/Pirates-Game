# Pirates-Game

Pirate game a game that returns us to the old days when we were just playing arcade games and we were so happy, this game has changed my mindset in making games with pygame because I have used a new technique I have not use before in the old simple games I started this game with a new order of sprites and classes and tons of files working together this helped me a lot at first I found some issues bcs first time working with all those complex stuff but when I turned to another project worked with same technique and returned to continue this project everything was clear and helped me a lot to handle all this complexity

## How to Run
### Option 1: Standalone Executable (Quickest)
Download the latest `.exe` file directly from the **[Releases](../../releases)** section and run it.

### Option 2: Run from Source
